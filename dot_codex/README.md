# Codex directory

chezmoi renders this directory to `~/.codex`, the user-scope configuration directory of the [Codex CLI](https://developers.openai.com/codex/cli). It gives Codex the Claude Code instructions in `~/.claude/CLAUDE.md` and `~/.claude/rules/`, the hooks in `~/.claude/hooks/`, and explicit access to commands through a Codex-only adapter skill. The Claude Code files stay unchanged. [`docs/agents/codex.md`](../docs/agents/codex.md) is the overview of what Codex loads from this repository.

| Path                                                                                             | What lives there                                                                                                                                                                                                                                                 |
| ------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [`skills/claude-command/SKILL.md`](skills/claude-command/SKILL.md)                               | Explicit-only adapter for `$claude-command git:commit:single`. Reads the selected Claude command on demand; stays outside the shared `.agents/skills` directory.                                                                                                 |
| [`skills/claude-command/scripts/read-command.py`](skills/claude-command/scripts/read-command.py) | Validates the command name and reads the selected Claude command.                                                                                                                                                                                                |
| [`skills/claude-command/test/read-command.py`](skills/claude-command/test/read-command.py)       | Checks command lookup and the explicit-only policy. Run: `python3 dot_codex/skills/claude-command/test/read-command.py` from the repository root.                                                                                                                |
| [`AGENTS.md.tmpl`](AGENTS.md.tmpl)                                                               | Renders `~/.codex/AGENTS.md` from `CLAUDE.md` and every rule in `dot_claude/rules/`.                                                                                                                                                                             |
| [`modify_hooks.json`](modify_hooks.json)                                                         | chezmoi modify script for `~/.codex/hooks.json`. Writes the same hook entries as the `hooks` block in [`dot_claude/settings.json`](../dot_claude/settings.json), plus `apply_patch`. Keeps the cmux handlers from the current file where `~/.cmux/hooks` exists. |
| [`modify_private_config.toml`](modify_private_config.toml)                                       | chezmoi modify script for `~/.codex/config.toml`. Sets the model, the reasoning effort, the `CODEX.md` project-instruction fallback, the Context7 MCP server with the API key from `.envrc`, and `features.memories`. Keeps the keys Codex and cmux write, and the file's formatting.                         |
| [`test/modify-config-toml.sh`](test/modify-config-toml.sh)                                       | Test for `modify_private_config.toml`. Run: `bash test/modify-config-toml.sh`.                                                                                                                                                                                   |
| [`hooks/apply-patch.sh`](hooks/apply-patch.sh)                                                   | Runs a Claude Code file hook once per file that a Codex `apply_patch` call wrote.                                                                                                                                                                                |
| [`hooks/test/test.sh`](hooks/test/test.sh)                                                       | Smoke test for the wrapper. Run: `bash hooks/test/test.sh`.                                                                                                                                                                                                      |
| [`hooks/test/modify-hooks-json.sh`](hooks/test/modify-hooks-json.sh)                             | Test for `modify_hooks.json`. Run: `bash hooks/test/modify-hooks-json.sh`.                                                                                                                                                                                       |
| [`docs/implementation.md`](docs/implementation.md)                                               | Why the template and the wrapper exist, and how each works.                                                                                                                                                                                                      |

Codex runs a hook only after you trust it. Open the Codex TUI once on the host and once in the devcontainer, and trust the hooks. After a change to a command, matcher, or timeout in `hooks.json`, trust them again. A change to a script needs no new trust.
