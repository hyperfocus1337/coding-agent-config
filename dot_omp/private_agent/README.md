# omp agent directory

chezmoi applies this directory to `~/.omp/agent`. This README stays in the repository. See [omp integration](../../docs/agents/omp.md) for discovery and verification details.

## Rules

[`RULES.md.tmpl`](RULES.md.tmpl) joins the top-level `dot_claude/rules/*.md` files into `~/.omp/agent/RULES.md`. It skips `README.md` and files with frontmatter so scoped rules do not become global. omp loads the result as always-apply instructions without an extension or imports in `CLAUDE.md`.

After editing a rule, run `just chezmoi`, then start a fresh omp session or use `/clear` or `/new`.

## Extensions

omp loads extensions from `~/.omp/agent/extensions/`, not from `~/.pi/agent/extensions/`. This directory puts no extension in that folder. The `extensions` setting in [`private_config.yml`](private_config.yml) loads the `pi.ts` of each hook in [`dot_claude/hooks/`](../../dot_claude/hooks/README.md), so omp runs the same code as pi. A hook with code for omp only also has an `omp.ts`, which omp loads after `pi.ts` or in place of it, see [omp code](../../docs/hooks/authoring.md#omp-code). Start a new omp session after `just chezmoi` to load an edit.
