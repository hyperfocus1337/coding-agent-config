# OpenRouter filter parameters

The query parameters that [openrouter.ai/models](https://openrouter.ai/models) accepts, with their allowed values. Read out of the page's own URL parser in the client bundle on 2026-09-19. Used by the links in [`model-pricing.md`](model-pricing.md).

Append to `https://openrouter.ai/models?`. Lists are comma separated.

| Parameter                                                         | Values                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| ----------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `fmt`                                                             | `cards` (default), `table`                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `order`                                                           | `most-popular`, `newest`, `oldest`, `top-weekly`, `weekly-tokens-low-to-high`, `discount-high-to-low`, `pricing-low-to-high`, `pricing-high-to-low`, `context-high-to-low`, `context-low-to-high`, `throughput-high-to-low`, `throughput-low-to-high`, `latency-low-to-high`, `latency-high-to-low`, `intelligence-high-to-low`, `intelligence-low-to-high`, `coding-high-to-low`, `coding-low-to-high`, `agentic-high-to-low`, `agentic-low-to-high`, `da-elo-high-to-low`, `da-elo-low-to-high` |
| `arch`                                                            | `GPT`, `Claude`, `Gemini`, `Gemma`, `Grok`, `Cohere`, `Nova`, `Qwen`, `Qwen3`, `Yi`, `DeepSeek`, `Mistral`, `Llama2`, `Llama3`, `Llama4`, `PaLM`, `RWKV`, `Router`, `Media`, `Other`                                                                                                                                                                                                                                                                                                              |
| `categories`                                                      | `programming`, `roleplay`, `marketing`, `marketing/seo`, `technology`, `science`, `translation`, `legal`, `finance`, `health`, `trivia`, `academia`                                                                                                                                                                                                                                                                                                                                               |
| `input_modalities`, `output_modalities`                           | `text`, `image`, `file`, `audio`, `video`                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `variant`                                                         | `free`, `extended`, `standard`, `thinking`, `batch`                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `supported_parameters`                                            | `tools`, `tool_choice`, `parallel_tool_calls`, `reasoning`, `reasoning_effort`, `include_reasoning`, `structured_outputs`, `response_format`, `seed`, `verbosity`, `web_search_options`, plus the sampling parameters                                                                                                                                                                                                                                                                             |
| `model_authors`                                                   | Author slug, the part before the `/` in a model id: `deepseek`, `moonshotai`, `z-ai`, `qwen`, `minimax`, `anthropic`, `openai`                                                                                                                                                                                                                                                                                                                                                                    |
| `providers`                                                       | Serving provider name, as the providers tab spells it                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `context`                                                         | Minimum context in tokens, for example `1000000`                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `min_price`, `max_price`                                          | Input price, USD per million tokens                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `min_output_price`, `max_output_price`                            | Output price, USD per million tokens                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `min_intelligence_index`, `min_coding_index`, `min_agentic_index` | Quality floors; `max_` variants exist                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `min_tool_success_rate`, `max_tool_success_rate`                  | Tool-call success rate                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `min_age_days`, `max_age_days`                                    | Age since release                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `zdr`, `hipaa`, `discount`, `active`, `private`                   | `true`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `distillable`                                                     | `true`, `false`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `region`                                                          | `eu`, `us`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `q`                                                               | Free-text search                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |

For a scripted answer instead of a page, use `GET https://openrouter.ai/api/v1/models` and `GET https://openrouter.ai/api/v1/models/<id>/endpoints`. The first returns the cheapest endpoint per model, the second every endpoint with its quantization.
