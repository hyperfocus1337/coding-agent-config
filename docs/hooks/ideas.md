# Hook ideas

The hooks and checks that [`dot_claude/hooks/`](../../dot_claude/hooks/README.md) does not have yet, proposed on 2026-10-22. A check that an existing hook should do, but misses, goes in [`gaps.md`](gaps.md), not here.

An idea is proposed until it lands. Remove a row in the same commit that builds it. When you reject an idea, move its row to [Rejected ideas](#rejected-ideas) with the reason, so nobody proposes it again. When the reason comes from design work on the idea, also record it in [`decisions.md`](decisions.md).

### `block-check-evasion`

Runs on `Stop` and reads `git diff`, so it sees only the lines that changed. `lint-code` and the type checkers exit 2, so a suppression or a skipped test is the shortest way past them. One hook protects all of them. Build it first, with `block-target-edits`.

| Idea                                                                                                                                                                                                 | Why                                                                                                                                             | Status                                                                     |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------- |
| Block a new lint or type suppression in added lines: `# noqa`, `// @ts-ignore`, `# type: ignore`, `oxlint-disable`, `# shellcheck disable=`                                                          | Protects `lint-code`, `type-check-tsc`, and `type-check-pyrefly`                                                                                | Proposed. Build first                                                      |
| Block a weakened test: a new `.skip`, `xit`, or `@pytest.mark.skip`, or a removed `assert`                                                                                                           | Same reason, for tests and for `run-tests`                                                                                                      | Proposed                                                                   |
| Block conflict markers and whitespace errors with `git diff --check`                                                                                                                                 | Built into git. One command                                                                                                                     | Proposed                                                                   |
| Report added debug code (`console.log`, `debugger`, `breakpoint()`, `import pdb`), comments that tell the change and not the code ("now uses", "previously", "NEW:"), and em dashes in code comments | Agent habits that the linters do not see. Vale reads only Markdown, Org, HTML, and text files, so `rules/writing.md` is not checked in comments | Proposed. Report only, do not block: some `console.log` calls are intended |

## Rejected ideas

| Idea                                                        | Why it was proposed                                             | Why it was rejected                                                                         |
| ----------------------------------------------------------- | --------------------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| Find dead code with knip or vulture, on `Stop`              | Matches "prefer deletion" in `rules/code.md`                    | It reports code that the agent did not change. Run it by hand                               |
| Find duplicate code with jscpd, on `Stop`                   | Matches "reuse it" in `rules/code.md`                           | Same reason as dead code                                                                    |
| Flag a new dependency in `package.json` or `pyproject.toml` | `rules/code.md`: never add a dependency for what a few lines do | The rule needs judgement. A hook sees only that a dependency was added, not if it is needed |
| Require a `shortcut:` comment on a deliberate shortcut      | `rules/code.md` defines the marker                              | A hook cannot find a shortcut that has no marker                                            |
