# Hook gaps

The places where a hook in [`dot_claude/hooks/`](../../dot_claude/hooks/README.md) does not cover what it should, in Claude Code, pi, omp, or Codex. The evidence for each gap is in [`research/hooks/hook-scoping.md`](../research/hooks/hook-scoping.md), checked on 2026-10-19 with Claude Code 2.1.303, pi 1.3.0, omp 18.12.2, and Codex 0.163.0.

A gap is open until a fix lands, or accepted when the reason in the status column says why no fix is necessary. Remove a row in the same commit as its fix. An omp fix goes in the `omp.ts` of the hook, so `pi.ts` keeps no omp code.
